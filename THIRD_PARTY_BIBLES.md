# Optional Bible resource: ASV

NEAR offers one optional Bible download: the American Standard Version (ASV,
1901). The source edition is public domain, as confirmed by
[eBible.org](https://ebible.org/asv/) and its
[ASV distribution page](https://ebible.org/find/show.php?id=eng-asv).

The downloadable SQLite database is from
[`midvash/bible-data`](https://github.com/midvash/bible-data), which identifies
the ASV as public domain and records eBible.org as its source. NEAR pins the
resource to commit `9586bd8228a747962df1ee8692730422fb7eb2ec` and verifies its
size and SHA-256 digest before installation. The 5.5 MB database is stored in
NEAR's app data directory and is not included in the app build or installer.
